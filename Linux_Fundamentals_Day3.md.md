**# Linux Fundamentals - Day 3**



\# What is Linux?



Linux is an open-source operating system used in servers, cloud computing, software development, and cyber security.



\# Linux Kernel



The Kernel is the core component of Linux. It manages hardware resources such as CPU, memory, storage, and devices.



\# Open Source



Linux is open source, which means its source code can be viewed, modified, and distributed by anyone.
